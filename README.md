## Selected work

### [WorkTracker — Product & Engineering Case Study](https://github.com/Gaan21/worktracker-case-study)

### [Agent Factory — Case Study](https://github.com/Gaan21/agent-factory-case-study)

An evolving, visual explanation of a personal AI agent factory: scoped tasks, isolated execution, automated checks, independent review, and human acceptance. It explains the workflow and its boundaries in plain language, distinguishing verified behavior from capabilities still under development.

### [dart-architecture-lints](https://github.com/Gaan21/dart-architecture-lints)

Executable static-analysis rules derived from recurring architecture and correctness failures. A real timezone defect led to root-cause analysis, three lint rules, automated tests, and CI checks designed to catch future occurrences earlier.

### [agent-guides-cli](https://github.com/Gaan21/agent-guides-cli)

Tooling, in development, for delivering versioned engineering guidance to coding agents. A project selects guidance bundles from Git repositories, pins the exact version, and connects them to Claude Code and OpenCode, so every session starts from the same written guidance. Shared bundles live in [agent-guides](https://github.com/Gaan21/agent-guides). Apache-2.0; no stable release yet.
